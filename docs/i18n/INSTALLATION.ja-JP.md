# RE:FRAME — Persona 3 Reload 1.1.5

作者は Aporia です。Steam で正規購入した Persona 3 Reload（アプリ ID **2161700**、ビルド **22672075**）が対象です。Windows x64 と DirectX 12 が必要です。

## 変更点

街のマップでも、選択した DLSS、FSR、XeSS のアップスケーリングモードを使用できます。3D 背景を補正できない場合は、マップを閉じるまでゲーム本来のレンダリングスケールに戻ります。

**シャープネス**は FidelityFX CAS により、DLAA、DLSS、FSR、XeSS の再構成後、HUD の描画前にシーンの細部を調整します。初期値は 0%（無効）で、100% まで 5% 刻みで設定できます。グラフィック設定で適用すると再起動せずに反映されます。方式や品質モードを変えても値は引き継がれます。標準TAAでは設定項目が表示されません。

## インストールと更新

1. ゲームを終了します。Steam で **プロパティ → インストール済みファイル → 参照** を開きます。
2. `P3R\Binaries\Win64` に `d3d12.dll` がある場合は、そのファイルを導入した MOD の削除手順に従います。 RE:FRAME を更新するには、旧バージョンの `Remove-ReFrame.ps1` を実行してから、新しい ZIP を展開してください。
3. ZIP の SHA-256 を同梱の `.sha256` ファイルと照合します。`P3R` フォルダーがある場所に **REFRAME-P3R-v1.1.5.zip** を展開します。Steam から起動し、グラフィック設定で方式、品質モード、シャープネスを選びます。

設定を保持するには `ReFrame\Settings.ini` を残します。以前の開発版から更新する場合は、RE:FRAME が新しいフォルダーに設定を保存するまで `P3RGraphicsEnhanced\Settings.ini` を残します。XeSS には Microsoft Visual C++ 再頒布可能パッケージ x64 14.40.33810 以降が必要です。

## アンインストール

ゲームを終了し、`P3R\Binaries\Win64\ReFrame` で `Remove-ReFrame.ps1` を実行します。`-WhatIf` で削除対象を確認できます。スクリプトはマニフェストとファイルのハッシュを確認し、設定とログを保持します。

## シャープネスの確認

同じシーン、方式、品質モード、カメラ位置で、0% と 100% を順に適用します。変更のたびにメニューを閉じます。髪や細かなテクスチャを見比べ、カメラを動かして輪郭、HUD、字幕を確認します。キャンセルで変更が取り消され、適用した設定が再起動後も残ることを確認します。

`P3R\Binaries\Win64\ReFrame\ReFrame.log` で使用中の方式と CAS を適用したフレーム数を確認できます。安定した 240 フレームの計測では、0% で `240 frames (0 CAS)`、全フレームに適用された場合は `240 frames (240 CAS)` と表示されます。

RTX 5060 を用い、DLSS、FSR、XeSS のパフォーマンスモードで 1080p のゲーム内検証を行いました。同 GPU で利用できる SDK の全 14 モードをオフラインでも検証しました。Radeon の FSR 4 と Intel Arc 向けに最適化された XeSS は、対応する実機での検証が残っています。
