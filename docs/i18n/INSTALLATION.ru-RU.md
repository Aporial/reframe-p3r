# RE:FRAME — Persona 3 Reload 1.1.0 · Обновление резкости

Автор — Aporia. Для легально купленной в Steam копии Persona 3 Reload, ID приложения **2161700**, сборка **22672075**. Требуются Windows x64 и DirectX 12.

## Что нового

**Резкость** использует FidelityFX CAS для настройки деталей после реконструкции DLAA, DLSS, FSR или XeSS, до отрисовки HUD. Доступны значения от 0% (по умолчанию выключено) до 100% с шагом 5%. Примените изменение в меню графики. Оно вступает в силу без перезапуска, значение сохраняется при смене технологии и режима качества. Оригинальный TAA скрывает этот пункт.

## Установка и обновление

1. Закройте игру. В Steam откройте **Свойства → Установленные файлы → Обзор**.
2. Если в `P3R\Binaries\Win64` уже есть `d3d12.dll`, следуйте инструкции по удалению мода, которому он принадлежит. При обновлении с тестовой версии RE:FRAME 1.1.0 сохраните копию её файлов и распакуйте финальную версию поверх неё.
3. Сравните SHA-256 архива с файлом `.sha256`. Распакуйте **REFRAME-P3R-v1.1.0.zip** в папку, содержащую `P3R`. Запустите игру через Steam и выберите технологию, режим качества и резкость в меню графики.

Чтобы сохранить настройки, оставьте `ReFrame\Settings.ini`. При переходе с ранней версии для разработчиков оставьте `P3RGraphicsEnhanced\Settings.ini`, пока RE:FRAME не сохранит данные в новую папку. Для XeSS нужен Microsoft Visual C++ Redistributable x64 версии 14.40.33810 или новее.

## Удаление

Закройте игру и запустите `Remove-ReFrame.ps1` из `P3R\Binaries\Win64\ReFrame`. Параметр `-WhatIf` показывает файлы к удалению. Скрипт сверяет манифест и контрольные суммы, сохраняя настройки и журналы.

## Проверка резкости

Примените 0%, затем 100% в одной сцене с одинаковыми технологией, режимом качества и положением камеры. Каждый раз выходите из меню. Сравните волосы и мелкие текстуры, затем поверните камеру и проверьте контуры, HUD и субтитры. Отмена должна отбросить изменение, а применение — сохранить его после перезапуска.

Журнал `P3R\Binaries\Win64\ReFrame\ReFrame.log` показывает активную технологию и число кадров с CAS. В стабильной выборке из 240 кадров при 0% ожидается `240 frames (0 CAS)`, а при обработке всех кадров — `240 frames (240 CAS)`.

Резкость проверена в игре при 1080p в режиме «Производительность» для DLSS, FSR и XeSS на RTX 5060. Автономные тесты охватили все 14 режимов SDK, доступных на этой видеокарте. FSR 4 на Radeon и XeSS, оптимизированный для Intel Arc, ещё нужно проверить на этих видеокартах.
