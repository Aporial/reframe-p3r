# RE:FRAME — Persona 3 Reload 1.1.4

제작자는 Aporia입니다. Steam에서 정식 구매한 Persona 3 Reload(앱 ID **2161700**, 빌드 **22672075**)를 대상으로 합니다. Windows x64와 DirectX 12가 필요합니다.

## 새로운 기능

도시 지도에는 게임 자체의 렌더링 배율이 적용되어 3D 배경이 지도 영역을 꽉 채웁니다. 지도를 닫으면 선택한 업스케일링 모드가 다시 적용됩니다.

**선명도**는 FidelityFX CAS를 사용해 DLAA, DLSS, FSR 또는 XeSS 재구성 후 HUD가 표시되기 전에 세부 표현을 조절합니다. 기본값은 0%(끔)이며 5% 단위로 100%까지 설정할 수 있습니다. 그래픽 메뉴에서 적용하면 다시 시작할 필요가 없습니다. 값을 기술과 품질 모드 간에 공유합니다. 기본 TAA에서는 이 항목이 숨겨집니다.

## 설치 또는 업데이트

1. 게임을 종료하세요. Steam에서 **속성 → 설치된 파일 → 찾아보기**를 엽니다.
2. `P3R\Binaries\Win64`에 `d3d12.dll`이 이미 있으면 해당 모드의 제거 안내를 따르세요. RE:FRAME을 업데이트하려면 이전 버전의 `Remove-ReFrame.ps1`을 실행한 뒤 새 ZIP 파일의 압축을 푸세요.
3. ZIP의 SHA-256을 동봉된 `.sha256` 파일과 비교하세요. `P3R` 폴더가 들어 있는 폴더에 **REFRAME-P3R-v1.1.4.zip**을 풉니다. Steam에서 게임을 시작하고 그래픽 메뉴에서 기술, 품질 모드, 선명도를 선택하세요.

설정을 유지하려면 `ReFrame\Settings.ini`를 보관하세요. 이전 개발 빌드를 업데이트할 때는 RE:FRAME이 새 폴더에 설정을 저장할 때까지 `P3RGraphicsEnhanced\Settings.ini`를 보관하세요. XeSS에는 Microsoft Visual C++ 재배포 가능 패키지 x64 14.40.33810 이상이 필요합니다.

## 제거

게임을 종료하고 `P3R\Binaries\Win64\ReFrame`에서 `Remove-ReFrame.ps1`을 실행하세요. `-WhatIf`로 제거 대상을 미리 확인할 수 있습니다. 스크립트는 매니페스트와 파일 해시를 확인하고 설정 및 로그를 보존합니다.

## 선명도 확인

같은 장면에서 기술, 품질 모드, 카메라 위치를 유지한 채 0%와 100%를 차례로 적용하세요. 변경할 때마다 메뉴를 닫습니다. 머리카락과 미세한 텍스처를 비교하고, 카메라를 움직이며 윤곽선, HUD, 자막을 확인하세요. 취소하면 변경이 사라지고 적용한 값은 재시작 후에도 유지되는지 확인하세요.

`P3R\Binaries\Win64\ReFrame\ReFrame.log`에서 활성 기술과 CAS가 처리한 프레임 수를 확인할 수 있습니다. 안정적인 240프레임 구간에서 0%는 `240 frames (0 CAS)`, 모든 프레임에 적용되면 `240 frames (240 CAS)`로 표시됩니다.

RTX 5060에서 DLSS, FSR, XeSS의 성능 모드로 1080p 게임 내 선명도를 확인했습니다. 같은 GPU에서 사용 가능한 SDK 모드 14개를 오프라인으로도 확인했습니다. Radeon의 FSR 4와 Intel Arc에 최적화된 XeSS는 해당 하드웨어에서 별도로 확인해야 합니다.
