# Manual Sharpness checks for RE:FRAME 1.1.0

Use Persona 3 Reload Steam build **22672075**. Check the archive's SHA-256 and back up any installed mod before following the [installation guide](INSTALLATION.md). Capture only relevant, redacted excerpts from `P3R/Binaries/Win64/ReFrame/ReFrame.log`.

1. **Menu and persistence.** Select DLAA, DLSS, FSR or XeSS in Graphics. Sharpness follows DLSS Model for NVIDIA and Quality Mode for AMD and Intel. Check mouse dragging, arrows, controller input, 5% steps and scrolling to the bottom. Cancel a draft, then apply 25% and restart. Switch quality mode, DLSS model and technology. Selecting Original TAA should hide Sharpness and returning to an SDK should restore 25%.
2. **Image quality.** Compare 0%, 25%, 50%, 75% and 100% from the same viewpoint. Examine hair, contours, textures, fine geometry and distant objects. Repeat in dark, bright and battle scenes. Move the camera and check for flicker, trailing and halos. Compare the HUD, text, subtitles and loading screen. Repeat with Native AA and an upscaling mode for each available SDK.
3. **Applying in-game.** In a stable mode, apply several Sharpness values with all other settings held constant. The log should show the new strength and CAS coverage without recreating the SDK feature or changing the viewport or jitter phases. If the first frame logs `reset 1`, record any preceding scene change, pause or viewport change. Try switching to Original TAA and back and changing the resolution and window mode.
4. **Resolution and language.** Try available 720p, 1080p, 1440p, 2160p and ultrawide resolutions. Check the image edges after a resize. Inspect the label, help text, and percent formatting in each language, paying attention to Japanese, Korean, and both Chinese variants.
5. **Performance.** Record the same sequence at 0% and 50%. Compare mean frame time and p95 in `Main-view cadence`. Stable samples should read `240 frames (0 CAS)` at 0% and `240 frames (240 CAS)` with full coverage. Check again after a scene transition. At 50%, a GPU capture should show one CAS dispatch and one `CopyTextureRegion` from `RE:FRAME CAS scratch` after the SDK. Use `sharpness_tests.exe --hardware` for isolated GPU time, CPU recording time and scratch allocation.

For a report, include the backend, mode, resolution, strength, scene, input method and relevant log excerpt. For a visual issue, include one frame at 0% and one at the value that shows the problem.
