# RE:FRAME — Persona 3 Reload v1.0.0

The first public release of RE:FRAME brings modern anti-aliasing and upscaling to Persona 3 Reload's native graphics menu.

- NVIDIA DLAA and DLSS, AMD FSR and Intel XeSS with up to 14 SDK modes and the game's Original TAA.
- Automatic render scale management, DLSS model selection and 13 interface languages.
- Launch directly from Steam. No ReShade, overlays, mod loaders or external applications.
- Compatible with earlier graphics settings. Returning to Original TAA applies the selected manual scale when confirming the same settings change.

## Download and install

Download **REFRAME-P3R-v1.0.0.zip** and **REFRAME-P3R-v1.0.0.zip.sha256**. Close the game and extract the archive into the Steam game root that contains the `P3R` folder. See the repository README for upgrade and removal steps.

This release targets Steam build **22672075**, Windows x64 and DirectX 12. SDK capabilities depend on the GPU and driver.
