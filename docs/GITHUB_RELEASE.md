# RE:FRAME — Persona 3 Reload v1.1.4 · City Map Fix

The city map's 3D background now fills the map area with Super Resolution enabled. The game uses its own scale while the map is open and restores the selected upscaling mode for gameplay when it closes.

## Download and install

Download **REFRAME-P3R-v1.1.4.zip** and its **.sha256** file from the release assets. Close the game and run the previous version's `Remove-ReFrame.ps1` if updating. Extract the new ZIP into the Steam game folder that contains `P3R`. The update preserves your saved settings and targets **Steam build 22672075**, Windows x64 and DirectX 12.

## Validation

The map fix was tested in build 1.1.3 on a GeForce RTX 5060 with FSR 3.1.6 Quality, DLSS Quality and XeSS Quality. The map rendered at 1920×1080 in all three modes. The journal also confirmed that FSR and DLSS resumed upscaling after the map closed. Version 1.1.4 ships the same rendering code and passed the Windows x64 build, CPU regressions and package checks.
