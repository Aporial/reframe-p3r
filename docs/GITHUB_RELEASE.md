# RE:FRAME — Persona 3 Reload v1.1.0 · Sharpness Update

**Sharpness** is now available in Persona 3 Reload's Graphics menu for DLAA, DLSS, FSR and XeSS, including Native AA. Choose 0–100% in 5% steps and apply the change in-game. The default is 0%. RE:FRAME saves one value across technologies and quality modes. Original TAA hides the control.

The update uses AMD FidelityFX Contrast Adaptive Sharpening on the reconstructed scene before the game draws the HUD. The frame log reports CAS coverage, and the ZIP includes localized guides and a hash-checked uninstaller.

## Download and install

Download **REFRAME-P3R-v1.1.0.zip** and **REFRAME-P3R-v1.1.0.zip.sha256**. Close the game and extract the ZIP into the Steam game folder that contains `P3R`. The release targets **Steam build 22672075**, Windows x64 and DirectX 12.

## Validation

Sharpness was checked in-game at 1080p with DLSS, FSR 3.1.6 and cross-vendor XeSS in Performance mode on a GeForce RTX 5060. All 14 available modes on that GPU passed standalone dispatch tests. Radeon FSR 4 and Intel-optimized XeSS on Arc still need testing on those GPUs. [Compatibility and measurements](https://github.com/Aporial/reframe-p3r/blob/v1.1.0/docs/COMPATIBILITY.md)
